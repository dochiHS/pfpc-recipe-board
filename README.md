# PFPC 레시피 보드

300mm EDGE POLISHING(이폴) 자리에서 다음 공정 PFPC가 지금 어떤 레시피로 도는지 보고, 그에 맞춰 이폴 생산 레시피를 정하는 시연판입니다.

- 화면: https://dochihs.github.io/pfpc-recipe-board/
- 구성: 이폴 4대, PFPC 1대(처리량 이폴 3대분), 레시피 4종
- 장비 이름, 레시피 이름, 상태 값은 모두 가상 데이터입니다. 실제 공장에서는 PFPC 장비나 MES에서 현재 레시피를 받아 같은 화면을 채우면 됩니다.

## 만든 배경

반도체 생산직(EDGE POLISHING) 근무 당시, 다음 공정 PFPC의 레시피를 확인하려고 매번 장비까지 걸어가야 했습니다. 레시피가 다르면 넘긴 웨이퍼는 기다려야 했습니다. 그때 선임께 요청했던 기능을 현장 구조에 맞춰 다시 설계했습니다.

## 역할

- 문제 정의, 현장 구조(장비 대수, PFPC 처리량), 판단 규칙: 강혜성
- 구현: Claude와 함께 작업
